# Lista para probar manualmente en Godot 4.5 — 1280 x 720

Esta lista se debe completar **después de ejecutar Godot**. No está marcada como completada.

- [ ] F5 abre menú y muestra texto completo sin solapamientos.
- [ ] Selección Luna/Venus/Marte con Tierra como origen; nombre y 1–4 jugadores.
- [ ] Constructor: 10 módulos visibles con scroll; cambios afectan masa/costo/potencia.
- [ ] Cambiar lanzador, órbita y plan terrestre cambia las restricciones.
- [ ] Laboratorio bloquea lanzamiento inválido y permite uno válido.
- [ ] Cuenta regresiva, despegue y audio del cohete.
- [ ] 10 incidentes, 3 elecciones por evento y cohete animado suavemente.
- [ ] Con 2 jugadores los 2 votan, se aplica decisión mayoritaria / empate explicado.
- [ ] Hay ruta ganadora y ruta con derrota (escenarios disponibles en tests/).
- [ ] Los tiempos simulados no bajan del Hohmann ideal usado.
- [ ] Al completar vuelo se abre el análisis NASA y no salta directo a resultados.
- [ ] Cada destino tiene 3 casos científicos y abre su URL oficial.
- [ ] Sin instrumentos correctos se reduce puntaje y plan terrestre limita transmisión.
- [ ] Resultados y Rewind comparan puntuación sin errores de interfaz.
- [ ] Exportar bitácora TXT y reanudar partida después de cerrar el juego.
- [ ] Preguntas de pretest y postest no son idénticas; pretest no revela respuestas.
- [ ] Probar ventana minimizada, maximizada, 1280x720 y una resolución inferior.
- [ ] No aparecen errores rojos en el depurador de Godot.

Si falla alguna casilla, se debe reparar antes de afirmar que el proyecto es apto para una demostración pública.
